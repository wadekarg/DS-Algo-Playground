Monotonic Stack

Stack maintaining monotonic order. Solves next-greater/smaller element problems in O(n).

Technique Monotonic O(n)

Key Facts

  • Time: O(n) — each element is pushed and popped at most once
  • Space: O(n) — stack can hold up to n elements in the worst case
  • Monotone increasing stack: pop when incoming element is smaller
  • Monotone decreasing stack: pop when incoming element is larger
  • Use case: next greater / smaller element, largest rectangle in histogram

How Monotonic Stacks Work

A monotonic stack is a stack that maintains a strict ordering — either all elements are increasing from bottom to top, or all are decreasing. You maintain this invariant by popping elements off the stack whenever an incoming element would violate the order.

The classic use case is the Next Greater Element problem: for each element in an array, find the first element to its right that is larger. The naive approach is O(n²). With a monotonic decreasing stack, you process each element once: push it if it's smaller than the top; if it's larger, pop elements from the stack — each popped element has its "next greater element" found. Since each element is pushed and popped at most once, the total time is O(n).

The key insight is that the stack acts as a "waiting list" of elements that have not yet found their answer. When an element is processed, it resolves the waiting elements it dominates. This pattern generalises to: next smaller element (monotonic increasing stack), previous greater element (same stack, look back instead of forward), and sliding window maximum (use a deque).

For the Largest Rectangle in Histogram, maintain a monotonic increasing stack of indices. When you find a bar shorter than the top of the stack, you've found the right boundary of the rectangle that the top bar could form. Calculate the area and pop.

  • Monotonic decreasing: pop when new element > top → finds next greater element.
  • Monotonic increasing: pop when new element < top → finds next smaller element.
  • Store indices on the stack (not values) so you can compute widths and distances.
  • Append a sentinel value (e.g. 0 at the end of histogram) to flush remaining stack elements.
  • Time is always O(n) — each element enters and exits the stack at most once.

Code Templates

Python 
# ── Daily Temperatures (next warmer day) ──────────────────────
def daily_temperatures(temps):
    n      = len(temps)
    result = [0] * n
    stack  = []          # indices, monotonic decreasing by temperature
    for i, t in enumerate(temps):
        while stack and temps[stack[-1]] < t:
            j = stack.pop()
            result[j] = i - j     # days until warmer temperature
        stack.append(i)
    return result

# ── Online Stock Span ─────────────────────────────────────────
class StockSpanner:
    def __init__(self):
        self.stack = []   # (price, span) — monotonic decreasing
    def next(self, price):
        span = 1
        while self.stack and self.stack[-1][0] <= price:
            span += self.stack.pop()[1]   # absorb smaller spans
        self.stack.append((price, span))
        return span

# ── Largest Rectangle in Histogram ───────────────────────────
def largest_rectangle(heights):
    max_area = 0
    stack    = []           # indices of bars (monotonic increasing height)
    heights  = heights + [0]  # sentinel flushes remaining stack
    for i, h in enumerate(heights):
        start = i
        while stack and heights[stack[-1]] > h:
            j        = stack.pop()
            width    = i - (stack[-1] + 1 if stack else 0)
            max_area = max(max_area, heights[j] * width)
            start    = j
        stack.append(start)
    return max_area
