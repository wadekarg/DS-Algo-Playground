Math & Geometry

Modular arithmetic, matrix rotation, geometry primitives.

Technique Geometry O(n²)

Key Facts

  • Matrix rotation (90°): transpose then reverse each row — O(n²) in place
  • Spiral traversal: shrink boundaries layer by layer — O(n*m)
  • Modular exponentiation (pow): O(log n) via fast power
  • GCD: Euclidean algorithm — O(log min(a, b))
  • Sieve of Eratosthenes: O(n log log n) for all primes up to n

How Math & Geometry Problems Work

Math and geometry problems test your ability to apply precise arithmetic reasoning to 2D structures like matrices and grids. The key is knowing which mathematical identity or formula unlocks the problem — once you see it, the code is usually straightforward.

Matrix rotation (90° clockwise): transpose the matrix (swap matrix[i][j] with matrix[j][i]), then reverse each row. This achieves in-place rotation in O(n²) time, O(1) extra space. Counter-clockwise: reverse each row first, then transpose.

Spiral traversal: maintain four boundaries (top, bottom, left, right) and shrink them as you peel off one layer at a time. Each full loop around the spiral peels one ring. This is O(n×m) time and O(1) space (excluding output).

Fast exponentiation (Pow(x, n)): instead of multiplying x by itself n times (O(n)), use the identity: x^n = (x^(n/2))^2 when n is even, x × x^(n-1) when n is odd. This gives O(log n) multiplications. Handle negative exponents with 1 / pow(x, -n).

  • Matrix rotate 90°: transpose then reverse rows. Three lines of code in Python.
  • GCD: gcd(a, b) = gcd(b, a % b) — Euclidean algorithm, O(log min(a,b)).
  • Spiral: shrink boundaries after each direction sweep. Check bounds before each sweep.
  • Integer overflow: in Python, ints are arbitrary precision — no overflow. In Java/C++, cast to long.

# ── Rotate Matrix 90° Clockwise (in-place) ────────────────────
def rotate(matrix):
    n = len(matrix)
    # Step 1: transpose
    for i in range(n):
        for j in range(i+1, n):
            matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]
    # Step 2: reverse each row
    for row in matrix:
        row.reverse()

# ── Spiral Matrix (return elements in spiral order) ───────────
def spiral_order(matrix):
    res = []
    top, bottom, left, right = 0, len(matrix)-1, 0, len(matrix[0])-1
    while top <= bottom and left <= right:
        for c in range(left, right+1):   res.append(matrix[top][c])
        top += 1
        for r in range(top, bottom+1):   res.append(matrix[r][right])
        right -= 1
        if top <= bottom:
            for c in range(right, left-1, -1): res.append(matrix[bottom][c])
            bottom -= 1
        if left <= right:
            for r in range(bottom, top-1, -1):  res.append(matrix[r][left])
            left += 1
    return res

# ── Fast Exponentiation ───────────────────────────────────────
def my_pow(x, n):
    if n == 0: return 1
    if n < 0:  return 1 / my_pow(x, -n)
    if n % 2 == 0:
        half = my_pow(x, n // 2)
        return half * half
    return x * my_pow(x, n - 1)

# ── GCD (Euclidean) ───────────────────────────────────────────
def gcd(a, b):
    while b:
        a, b = b, a % b
    return a
