Advanced Graphs

Dijkstra, Bellman-Ford, Prim, Kruskal, and topological sort for weighted graphs.

Technique Dijkstra Kruskal

Key Facts

  • Dijkstra: O((V + E) log V) with binary heap — single-source shortest path (no negative weights)
  • Bellman-Ford: O(V * E) — handles negative weights, detects negative cycles
  • Prim's MST: O((V + E) log V) — grows MST one vertex at a time
  • Kruskal's MST: O(E log E) — sorts edges, uses Union-Find
  • Topological Sort: O(V + E) — valid only for DAGs

How Advanced Graph Algorithms Work

Dijkstra's algorithm finds the shortest path from a single source in a weighted graph with non-negative weights. It uses a min-heap (priority queue) and greedily expands the closest unvisited node. At each step it relaxes edges — if the newly discovered path to a neighbour is shorter than the current best, it updates the cost. Time: O((V+E) log V).

Bellman-Ford also finds shortest paths but handles negative edge weights. It relaxes ALL edges V−1 times. If after V−1 iterations an edge can still be relaxed, there is a negative cycle. Time: O(V·E) — slower than Dijkstra but necessary for negative weights.

Prim's algorithm builds a Minimum Spanning Tree (MST) — a tree connecting all nodes with minimum total edge weight. It greedily adds the cheapest edge that extends the current tree. Kruskal's algorithm is an alternative: sort all edges by weight, then add edges one by one using Union-Find to avoid cycles.

Topological Sort orders nodes in a Directed Acyclic Graph (DAG) so that every edge goes from an earlier node to a later one. It's used for dependency resolution, build systems, course scheduling. Use DFS (reverse post-order) or Kahn's algorithm (BFS with in-degree tracking).

  • Dijkstra: non-negative weights, single source. Uses a min-heap.
  • Bellman-Ford: handles negative weights, detects negative cycles.
  • Prim / Kruskal: both produce MSTs — Kruskal sorts edges + Union-Find, Prim grows from a node.
  • Topo sort: only valid for DAGs. Kahn's BFS version detects cycles too.

Code Templates

Python 
import heapq

# ── Dijkstra (single-source shortest path, non-negative weights) ──
def dijkstra(graph, src):
    # graph: {node: [(cost, neighbour), ...]}
    dist = {node: float("inf") for node in graph}
    dist[src] = 0
    heap = [(0, src)]          # (cost, node)
    while heap:
        cost, u = heapq.heappop(heap)
        if cost > dist[u]:
            continue           # already found a shorter path
        for w, v in graph[u]:
            if dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
                heapq.heappush(heap, (dist[v], v))
    return dist

# ── Kahn's Topological Sort (BFS + in-degree) ──────────────────
from collections import deque

def topo_sort(n, prereqs):
    # n nodes (0..n-1), prereqs = [[a,b], ...] means b→a
    graph  = [[] for _ in range(n)]
    indeg  = [0] * n
    for a, b in prereqs:
        graph[b].append(a)
        indeg[a] += 1
    q = deque(i for i in range(n) if indeg[i] == 0)
    order = []
    while q:
        node = q.popleft()
        order.append(node)
        for nb in graph[node]:
            indeg[nb] -= 1
            if indeg[nb] == 0:
                q.append(nb)
    return order if len(order) == n else []  # empty = cycle detected
