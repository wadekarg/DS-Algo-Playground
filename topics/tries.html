Tries

A Trie (prefix tree) is a tree where each node represents a character. Enables O(L) insert, search, and prefix queries for strings — far faster than O(L * N) with a hash set when prefix matching is needed.

Data Structure Prefix Tree O(L)

Key Concepts

  • TrieNode — Each node has a children dict (or array of 26) and an is_end flag.
  • Insert — Walk characters, create nodes as needed, set is_end on the last node.
  • Search — Walk characters; return is_end at the last node. Return false if any node is missing.
  • startsWith — Same as search but don't check is_end.
  • When to use — Autocomplete, spell-check, IP routing, word dictionaries, prefix queries.

How Tries Work

A Trie (pronounced "try", from retrieval) is a tree where each node represents a character. Words are stored by following a path from the root, one character at a time. The root is empty; each level represents one position in the string.

Every node has a dictionary of children (one per possible next character) and a boolean is_end flag marking that a complete word ends at this node. To insert a word, walk each character creating nodes as needed and set is_end = True on the last node. To search, walk the characters — if any character is missing, the word does not exist. To check a prefix, do the same walk but ignore is_end.

Tries shine when you need prefix matching on a large set of words — autocomplete, spell checking, IP routing. A hash set can tell you if a word exists in O(L), but it cannot tell you "does any word start with this prefix?" without scanning everything. A Trie answers prefix queries in O(L) too.

  • Space: O(N × L) total — N words of average length L. Each node can have up to 26 children for lowercase English.
  • Use over a hash set when you need prefix queries or word-by-word character matching.
  • Wildcards: use DFS and try all children when you hit a . character.

Code Templates

Python 
class TrieNode:
    def __init__(self):
        self.children = {}   # char → TrieNode
        self.is_end   = False

class Trie:
    def __init__(self):
        self.root = TrieNode()

    def insert(self, word: str) -> None:
        node = self.root
        for ch in word:
            if ch not in node.children:
                node.children[ch] = TrieNode()
            node = node.children[ch]
        node.is_end = True

    def search(self, word: str) -> bool:
        node = self.root
        for ch in word:
            if ch not in node.children:
                return False
            node = node.children[ch]
        return node.is_end

    def starts_with(self, prefix: str) -> bool:
        node = self.root
        for ch in prefix:
            if ch not in node.children:
                return False
            node = node.children[ch]
        return True  # prefix exists; don't check is_end

# Usage
trie = Trie()
trie.insert("apple")
trie.insert("app")
print(trie.search("app"))        # True
print(trie.search("appl"))       # False
print(trie.starts_with("appl"))  # True
