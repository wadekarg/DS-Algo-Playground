Bit Manipulation

AND, OR, XOR, shifts. Solve subset, parity, and counting problems in O(1) space.

Technique XOR O(1) space

Key Facts

  • AND (a & b): 1 only when both bits are 1 — useful for masking
  • OR (a | b): 1 when either bit is 1 — useful for setting bits
  • XOR (a ^ b): 1 when bits differ — self-cancels duplicates
  • Left shift (a << k): multiply by 2^k
  • Right shift (a >> k): integer divide by 2^k
  • n & (n-1): clears the lowest set bit — counts set bits in O(set bits)

How Bit Manipulation Works

Computers store all numbers as binary sequences of 0s and 1s. Bit manipulation operates directly on those bits using bitwise operators — and, or, xor, not, left shift, right shift. These operations run in O(1) time and O(1) space, making them extremely fast for the right class of problems.

The most powerful operator is XOR (^). It returns 1 when bits differ. Key property: a ^ a = 0 and a ^ 0 = a. This means XOR-ing a number with itself cancels it out — so XOR-ing an entire array finds the one element that appears an odd number of times. This trick solves "Single Number" in O(n) time and O(1) space with no hash map.

AND (&) is used for masking — isolate specific bits. n & 1 checks if n is odd. n & (n-1) clears the lowest set bit (useful for counting set bits). Left shift (<<) multiplies by 2: 1 << k creates a mask with only bit k set. Right shift (>>) divides by 2 (integer division).

Bit manipulation is useful for subset enumeration, power-of-two checks, encoding/decoding packed data, and anywhere you need O(1) space arithmetic tricks.

  • n & (n-1) — clears lowest set bit. Iterate this to count set bits in O(popcount) time.
  • n & (-n) — isolates the lowest set bit (used in Fenwick Trees).
  • 1 << k — creates bit mask for position k. Check: n & (1<<k) != 0.
  • a ^ b ^ b = a — XOR is its own inverse. Use to find missing or unique numbers.
  • Subset enumeration: loop mask from 0 to (1<<n)-1; bit k set = element k in subset.

Code Templates

Python 
# ── XOR trick: find the one unique number ─────────────────────
def single_number(nums):
    result = 0
    for n in nums:
        result ^= n       # duplicates cancel: a^a=0
    return result

# ── Count set bits (Kernighan's method) ───────────────────────
def count_bits(n):
    count = 0
    while n:
        n &= n - 1        # clear lowest set bit
        count += 1
    return count

# ── Check power of two ────────────────────────────────────────
def is_power_of_two(n):
    return n > 0 and (n & (n - 1)) == 0

# ── Reverse 32 bits ───────────────────────────────────────────
def reverse_bits(n):
    result = 0
    for _ in range(32):
        result = (result << 1) | (n & 1)
        n >>= 1
    return result

# ── Enumerate all subsets of a list ───────────────────────────
def all_subsets(nums):
    n = len(nums)
    subsets = []
    for mask in range(1 << n):
        subset = [nums[i] for i in range(n) if mask & (1 << i)]
        subsets.append(subset)
    return subsets
